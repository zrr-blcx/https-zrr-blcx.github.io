## 🧠 项目定位

在汽车电子 / 机器人系统中，CAN 总线承载着诊断、刷写、实时控制等关键任务。当多个节点同时发起高优先级诊断请求时，总线如何保证确定性？当晶体振荡器出现微小频偏时，同步机制是否依然鲁棒？当某个 ECU 失去应答能力时，错误界定与恢复能否按预期执行？  
这些不是纯软件协议栈能回答的问题——必须回到**物理层波形**。

本项目通过在两个 STM32F407 节点间构造精确的竞争、偏移与错误注入条件，验证 ISO 11898-1 定义的：
- 非破坏性逐位仲裁
- 硬同步与重同步
- ACK 错误 / 位填充错误的错误帧与恢复时序
- 故障界定状态机（Error Active / Passive / Bus Off）-故障界定状态机（错误激活/被动/总线关闭）

并在此过程中，关联功能安全中的**通信丢失检测、截止时间监控、故障容错时间窗口**等概念，为安全档案中的“安全机制验证”提供底层的物理证据。
